# Workflow: gsd-planner

Read `gsd/SPEC.md`, `gsd/STATE.md`, `MISSION.md`, and `gsd/ARCHITECTURE.md`.
Generate or refine a highly detailed, verifiable implementation plan for the current or upcoming phase. Update `gsd/PLAN.md` directly and ensure each step is small, testable, and explicitly maps to a requirement. Provide a summary artifact of the changes.
