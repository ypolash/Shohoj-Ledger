# Workflow: gsd-code-reviewer

Perform a rigorous code review of recently modified files or a requested component. 
Ensure the code fully adheres to the design constraints in `gsd/ARCHITECTURE.md` (e.g., 600-line limits, modularity, JSDoc presence) and meets the functional requirements defined in `gsd/SPEC.md`. Highlight any deviations and suggest concrete fixes.
