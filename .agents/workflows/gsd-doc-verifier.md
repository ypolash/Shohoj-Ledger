# Workflow: gsd-doc-verifier

Review the current codebase and verify if it matches the documentation in `gsd/SPEC.md`, `gsd/ARCHITECTURE.md`, and `gsd/STATE.md`. 
Report any discrepancies, outdated documentation, or undocumented code, and propose necessary updates to the markdown files to keep the context engine perfectly aligned with the codebase.
